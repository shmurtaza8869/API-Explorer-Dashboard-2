Project Overview

This project is a Postman Collection containing 6 saved and documented API requests using multiple free APIs. The purpose of this project is to understand how APIs work by sending requests, analyzing responses, and understanding how different HTTP methods are used.

Objectives
Understand how GET, POST, and DELETE requests work.
Practice using query parameters.
Learn how to read and understand API responses.
Understand how APIs can be used in real-world applications.
Organize and document API requests using Postman.
API Requests
#	Method	API	Purpose
1	GET	Weather API	Get weather information for Rawalpindi
2	GET	REST Countries API	Get country information
3	GET	Books API	Search or retrieve book information
4	POST	JSONPlaceholder	Create a fake blog post
5	DELETE	JSONPlaceholder	Delete a fake blog post
6	GET	Free API	Retrieve data from another public API
GET Requests

The GET requests demonstrate how to retrieve data from APIs using query parameters. For example, the weather request uses Rawalpindi as the location to retrieve weather-related information.

POST Request

The POST request is sent to JSONPlaceholder to create a fake blog post. It demonstrates how data can be sent to an API through the request body.

DELETE Request

The DELETE request demonstrates how a resource can be removed using an API. JSONPlaceholder simulates the deletion of a blog post.

Documentation

Each request contains a description explaining:

What the request does
What the response means
What the API could be used for

What I Learned

Through this project, I learned how API requests and responses work, how to use query parameters, how different HTTP methods are used, and how to analyze JSON responses. This project builds a foundation for working with APIs before moving on to JavaScript and full-stack development.
